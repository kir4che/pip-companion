在有视频的网页按下 Shift + Alt/Opt + P，即可快速开启或关闭画中画（PiP）。

【功能特色】
• PiP 播放控制：播放／暂停、拖动进度条或输入时间跳转、音量／静音、倍速及逐帧播放；支持的网站可切换到下一部视频。
• 播放列表与缩略图预览：支持 YouTube、Bilibili 和巴哈姆特动画疯；可浏览播放列表，并在进度条上预览缩略图。
• 字幕：在 PiP 中显示视频可读取的字幕，并自定义字体、大小、颜色等样式。
• 弹幕：显示 Bilibili、巴哈姆特动画疯的原生弹幕，或将 YouTube、Twitch 聊天室转换为弹幕；可在 Bilibili、巴哈姆特动画疯和 YouTube 直播的 PiP 中发送弹幕，并自定义显示样式。
• 浮动评论区：支持 YouTube 和 Bilibili，观看视频时也能浏览评论。
• 截图：在支持的平台上可将视频画面保存为 PNG
• 视频跟随：启用后，PiP 视频暂停时可切换到其他正在播放的视频。
• 窗口与快捷键：可根据视频比例调整 PiP 窗口，并自定义 PiP 和各项功能的快捷键。
• 设置页面可切换弹幕、截图、浮动评论区和视频跟随，调整跳转时长、字幕／弹幕样式及界面语言（繁体中文、简体中文、英文）。
• 支持符合条件的嵌入式视频；实际兼容性取决于网站结构和浏览器限制。

平台支持与限制：https://github.com/kir4che/pip-companion/blob/main/docs/platform-support.zh-TW.md

【隐私与支持】
• 不收集个人信息用于分析；发送弹幕等功能会根据你的操作与相应平台通信。
