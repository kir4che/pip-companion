# 平台支援與限制

> 下表列出主要測試平台的功能支援；其他採用標準 HTML5 播放器的網站通常也支援基本 PiP、播放控制與截圖。

| 功能             | YouTube                | Bilibili               | Twitch           | 巴哈動畫瘋             | Netflix           |
| ---------------- | ---------------------- | ---------------------- | ---------------- | ---------------------- | ----------------- |
| 播放／音量       | ✅                     | ✅                     | ✅               | ✅                     | ✅                |
| 倍速             | ✅（非直播）           | ✅（非直播）           | ✅（非直播）     | ✅                     | ✅                |
| 字幕             | ✅                     | ✅（先開啟原生字幕）   | ❌               | ❌                     | ✅                |
| 彈幕／聊天室顯示 | ✅（聊天室轉換）       | ✅（原生彈幕）         | ✅（聊天室轉換） | ✅（原生彈幕）         | ❌                |
| 彈幕／聊天室發送 | ✅（直播；依頻道權限） | ✅（依登入與平台權限） | ❌               | ✅（需登入與平台權限） | ❌                |
| 下一部           | ✅（播放清單）         | ✅（播放清單／番劇）   | ❌               | ✅                     | ✅                |
| 播放清單         | ✅                     | ✅                     | ❌               | ✅                     | ❌                |
| 縮圖預覽         | ✅                     | ✅                     | ❌               | ✅                     | ❌                |
| 截圖             | ✅                     | ✅                     | ✅               | ✅                     | ❌（受 DRM 限制） |

> 表格僅列出主要測試平台，其他網站尚未完整驗證，實際支援依網站與瀏覽器限制而定。
