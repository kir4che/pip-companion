幕伴 PiP（PiP Companion）隐私政策

最后更新：2026-11-06

一、权限与数据处理
本扩展程序没有账号、广告、分析或跟踪，也没有用于收集数据的开发者服务器。内容脚本会在支持平台（清单见 README）自动运行；在其他网站，只有用户打开扩展程序弹窗并启用 PiP 后才会注入，Chrome 通过 activeTab 临时授权当前标签页。扩展程序使用 storage 保存本地设置、使用 scripting 注入内容脚本，host permissions 仅限于支持平台，不会请求访问所有网站。视频、字幕、聊天室／弹幕及播放器状态均在本地处理；网页内容不会发送给开发者。

快捷键、功能开关、跳转秒数、界面语言、播放栏自定义项与 PiP 外观主题色、空降自动跳转开关、弹幕过滤关键字、字幕和弹幕外观设置，以及字幕翻译偏好设置（例如目标语言和显示模式）会保存在浏览器的扩展程序本地存储空间；PiP 标签页和播放状态、窗口大小与位置，以及各标签页的额外弹幕来源设置会暂存在会话存储区。浏览器会话结束时，会话数据会清除；关闭标签页时，该标签页的弹幕设置会移除。截图由用户主动触发，并下载到自己的设备；截图内容为当前 PiP 画面，可能包含字幕或弹幕等叠加层。

在 PiP 使用机器翻译时，字幕文本与目标语言会传送给所选服务（Microsoft Edge、Google 翻译、Azure Translator、Google Cloud Translation、DeepL）。扩展程序也可能查询可用语言；设置页的连接测试会传送一小段示例文本。API 密钥与 Azure 区域设置存于浏览器本地存储空间（免密钥服务免填）。密钥只随请求传给所选服务，不会传给本项目；可在字幕翻译设置中移除。字幕文本不会传送给开发者。

二、第三方服务
使用弹幕功能时，扩展程序会从支持网站页面读取聊天室／弹幕内容；弹幕（Bilibili、巴哈、Twitch）、字幕及缩略图预览等功能会直接向相关平台 API 或图片主机请求数据（包含 Twitch 聊天与表情图片主机）。这些请求可能包含视频标识信息、弹幕分段信息，以及该网站本身的 Cookie（用于带入用户的登录状态）；Cookie 不会传给开发者，也不会用于跨站跟踪。实际内容依功能、请求方式与浏览器设置而异。仅在用户主动从 PiP 发送弹幕时，消息才会通过网站原生输入框及用户的登录会话送至巴哈动画疯、Bilibili 或 YouTube，不会送至开发者。本扩展程序可能接触的第三方服务包括 Google、Microsoft、Azure、DeepL、Twitch、Bilibili、巴哈动画疯与 YouTube，各服务依其隐私政策处理数据。

三、保存与删除
移除扩展程序或清除浏览器的扩展程序数据，可删除本地设置；会话数据会在会话结束后清除。已下载的截图由用户自行管理。第三方请求数据的保存方式由各服务决定。

四、政策与联系
政策如有更新，会公布于本文件。若有隐私相关问题，请通过项目 [Issues](https://github.com/kir4che/pip-companion/issues) 联系。
