幕伴 PiP（PiP Companion）隐私政策

最后更新：2026-10-15

一、数据处理
本扩展程序没有账号、广告、分析或跟踪，也没有用于收集数据的开发者服务器。内容脚本会在列出的支持平台自动运行；在其他网站，只有用户打开扩展程序弹窗并启用 PiP 后才会注入，Chrome 通过 activeTab 临时授权当前标签页。扩展程序不会请求访问所有网站。视频、字幕、聊天室／弹幕及播放器状态均在本地处理；网页内容不会发送给开发者。

快捷键、功能开关、跳转秒数、界面语言、字幕和弹幕外观设置，以及字幕翻译偏好设置（例如目标语言和显示模式）会保存在浏览器的扩展程序本地存储空间；PiP 标签页和播放状态、窗口大小与位置，以及各标签页的额外弹幕来源设置会暂存在会话存储区。浏览器会话结束时，会话数据会清除；关闭标签页时，该标签页的弹幕设置会移除。截图由用户主动触发，并下载到自己的设备。

在 PiP 中使用机器翻译时，字幕文本和目标语言会直接发送给所选服务：Microsoft Translator、Google Cloud Translation 或 DeepL。扩展程序也可能向服务查询可用语言；设置页面的连接测试会发送一小段示例文本。用户提供的 API 密钥和 Microsoft 区域设置会保存在浏览器的扩展程序本地存储空间。密钥只会随请求发送给所选翻译服务，不会发送给本项目。可在字幕翻译设置中移除当前所选服务的密钥；字幕文本不会发送给开发者。

二、第三方服务
使用弹幕功能时，扩展程序会从受支持的网站页面读取聊天室／弹幕内容；弹幕（Bilibili、巴哈姆特动画疯、Twitch）、字幕及缩略图预览等功能会直接向相关平台 API 或图片主机请求数据（包括 Twitch 聊天室和表情图片主机）。这些请求可能包含视频标识信息、弹幕分段信息及 Cookie，具体内容取决于所用功能、请求方式和浏览器设置。从 PiP 发送弹幕时，消息会通过网站原生输入框和用户的登录会话发送到巴哈姆特动画疯、Bilibili 或 YouTube，不会发送给开发者。各服务会依照其隐私政策处理数据。

三、保存与删除
移除扩展程序或清除浏览器中的扩展程序数据，可以删除本地设置；会话数据会在浏览器会话结束后清除。已下载的截图由用户自行管理。第三方服务决定其请求数据的保存方式。

四、政策与联系
如有政策更新，将公布于本文档。如有隐私相关问题，请通过项目 [Issues](https://github.com/kir4che/pip-companion/issues) 联系。
