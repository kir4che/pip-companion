## v0.5.0

- 新增多軌與雙語字幕，並支援 Microsoft Translator、Google Cloud Translation、DeepL 即時翻譯（需自備 API 金鑰）
- 新增 Bilibili、巴哈動畫瘋、Twitch 與 YouTube 額外彈幕來源
- 新增 Netflix 進度條縮圖預覽
- 新增關閉 PiP 時暫停播放的設定
- 新增通用網站的集數導覽，並改善原生字幕與 Video.js 字幕覆蓋層偵測
- 改善播放復原與網站替換影片時的銜接，包含可存取嵌入式影片的原生 PiP 換片
- 修正懸停預覽干擾 PiP 影片選擇，以及頁面空白處的懸停狀態阻擋換片
- 改善字幕請求復原、PiP 清理及擴充功能訊息處理的穩定性

## v0.5.0-beta.1

- 將字幕系統升級為多軌／雙語字幕，可依影片提供的語言切換字幕軌
- 新增即時字幕翻譯，支援 Microsoft Translator、Google Cloud Translation、DeepL（需自備 API 金鑰）
- 新增額外彈幕來源，可將 Bilibili、巴哈動畫瘋或 Twitch 的彈幕／聊天室疊加到其他影片
- 修正 PiP「下一部」按鈕在播放器容器內的查找範圍
- 修正 PiP 控制焦點與面板關閉體驗
- 修正非同步關閉 PiP 時的提前關閉問題
- 修正重複注入 content script 的問題

## v0.4.0

- 新增繁體中文、簡體中文與英文介面，並可在設定頁切換語言
- 新增獨立設定頁，可自訂快捷鍵、跳轉秒數、功能開關，以及字幕與彈幕外觀
- 新增縮圖預覽開關，可在彈出視窗與設定頁切換進度條縮圖預覽

## v0.3.1

- 修正 Bilibili 縮圖未依目前分 P 載入，導致播放清單縮圖錯集或載入異常的問題
- 修正啟用「影片跟隨」時，PiP 誤切換至滑鼠懸停觸發的影片預覽

## v0.3.0

- 新增 YouTube、Bilibili 與巴哈動畫瘋共用的 PiP 播放清單，並在平台提供片長時顯示影片時間
- 修復 Netflix PiP 跳轉功能，並改善跨平台播放來源復原與下一部影片銜接
- 改善 Popup、PiP 與浮動留言區的無障礙操作，包含鍵盤與螢幕閱讀器支援
- 改善直播 PiP 時間顯示，並調整播放清單、控制列與彈幕輸入體驗

## v0.2.0

- 新增 PiP 彈幕輸入控制，支援的網站可直接從 PiP 發送彈幕或留言 #5
- 新增 `R` 快捷鍵，可依影片比例自動調整 PiP 視窗大小
- 新增可自訂的跳轉秒數：1、3、5、10、15 或 30 秒，預設為 5 秒
- 現在影片尚未準備完成時，也可以先開啟 PiP
- 改善 PiP 生命週期清理及擴充功能訊息處理的穩定性

## v0.1.0

- 提供子母畫面播放控制：播放／暫停、跳轉、音量、倍速、逐格播放及輸入時間跳轉
- 在 PiP 中顯示字幕，並可自訂字體、大小、顏色等樣式 #5
- 支援 Bilibili、巴哈動畫瘋原生彈幕，以及 YouTube 直播和 Twitch 聊天室留言
- 可在 YouTube、Bilibili 影片頁面開啟浮動留言區
- 將影片畫面截圖並儲存為 PNG
- 支援 YouTube、Bilibili、巴哈動畫瘋的進度條縮圖預覽
- 提供快捷鍵及彈出視窗設定，可切換功能並自訂彈幕外觀 #5
- 偵測支援的嵌入式影片；實際相容性依網站結構及瀏覽器限制而異
