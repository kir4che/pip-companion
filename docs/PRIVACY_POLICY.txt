PiP Companion Privacy Policy

Last updated: 2026-11-06

1. Permissions and data processing
The extension has no accounts, advertising, analytics, or tracking, and the developer operates no server to collect user data. Content scripts run automatically on supported platforms (see README for the list). On other websites, they are injected only after the user opens the extension popup and activates PiP; Chrome grants temporary access to that tab through activeTab. The extension uses storage to store local settings and scripting to inject content scripts; host permissions are strictly limited to supported platforms and do not request access to all websites. Video, subtitles, chat/danmaku, and player state are processed locally; page content is not sent to the developer.

Shortcuts, feature toggles, seek intervals, UI language, player bar custom items and PiP theme color, auto-jump toggle, danmaku blocklist keywords, subtitle and danmaku appearance settings, and subtitle translation preferences (such as target language and display mode) are stored in the browser's local extension storage. The PiP tab and playback state, window bounds, and per-tab extra-danmaku settings are kept in session storage. Session data is cleared when the browser session ends; per-tab danmaku settings are removed when that tab closes. Screenshots are triggered actively by the user and downloaded to their device; screenshot contents capture the current PiP frame and may include overlays such as subtitles or danmaku.

When machine translation is used in PiP, subtitle text and the target language are sent to the selected service (Microsoft Edge, Google Translate, Azure Translator, Google Cloud Translation, DeepL). The extension may also query available languages; the connection test in settings sends a short sample text. API keys and Azure region settings are stored in local browser storage (not required for keyless services). Keys are only sent to the selected service with requests, never to this project; they can be removed in Subtitle translation settings. Subtitle text is not sent to the developer.

2. Third-party services
When danmaku features are used, the extension reads chat/danmaku content from supported site pages. Features such as danmaku (Bilibili, Bahamut, Twitch), subtitles, and thumbnail previews make direct requests to the relevant platform APIs or image hosts (including Twitch chat and emote hosts). These requests may include video identifiers, danmaku segment information, and the website's own cookies (used to convey user login state); cookies are not sent to the developer and are not used for cross-site tracking. Actual content varies depending on feature, request method, and browser settings. Only when the user actively sends danmaku from PiP is the message sent to Bahamut Anime Crazy, Bilibili, or YouTube through the site's native input element and the user's signed-in session; it is never sent to the developer. Third-party services that the extension may interact with include Google, Microsoft, Azure, DeepL, Twitch, Bilibili, Bahamut Anime Crazy, and YouTube; each service handles data according to its own privacy policy.

3. Retention and deletion
Removing the extension or clearing extension data in the browser deletes local settings. Session data is cleared when the browser session ends. Downloaded screenshots are managed by the user. Each third-party service determines the retention policy for its request data.

4. Policy and contact
Any updates to this policy will be published in this document. For privacy-related inquiries, please contact us via project [Issues](https://github.com/kir4che/pip-companion/issues).
