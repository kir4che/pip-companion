PiP Companion Privacy Policy

Last updated: 2026-10-15

1. Data processing
The extension has no accounts, advertising, analytics, or tracking, and the developer operates no server to collect user data. Content scripts run on regular webpages to find videos and process video, subtitles, chat/danmaku, and player state locally. Page content is not sent to the developer.

Shortcuts, feature toggles, seek interval, UI language, subtitle and danmaku appearance settings, and subtitle translation preferences (such as target language and display mode) are stored in the browser's local extension storage. The source-tab identifier, playback state, and PiP window size and position are kept temporarily in session storage while PiP is in use. Screenshots are downloaded to the user's device when requested.

When the user enables subtitle translation and configures a provider, the extension sends subtitle text and the selected target language directly to the configured provider: Microsoft Translator, Google Cloud Translation, or DeepL. Translation is requested only while subtitle translation is enabled in PiP, apart from the short sample text sent by the settings connection test. The extension does not send subtitle text to the developer. API keys and the Microsoft region setting are stored in the browser's local extension storage so the feature can use the selected provider; users can remove them from the Subtitle translation settings at any time.

2. Third-party services
When danmaku features are used, the extension reads chat/danmaku content from supported site pages. For features such as danmaku (Bilibili, Bahamut, Twitch), subtitles, and thumbnail previews, it also makes direct requests to the relevant platform APIs or image hosts (including Twitch chat and emote hosts). These requests may include video identifiers, danmaku-segment information, and cookies, depending on the feature, request, and browser settings. When sending danmaku from PiP, the message is sent to Bahamut Anime Crazy, Bilibili, or YouTube through the site's native composer and the user's signed-in session; it is not sent to the developer. Each service handles data under its own privacy policy.

3. Retention and deletion
Removing the extension or clearing its browser data deletes local settings. Session data is cleared when the browser session ends. Users manage downloaded screenshots themselves. Each third-party service determines how long it retains its request data.
