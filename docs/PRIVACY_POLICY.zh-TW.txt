幕伴 PiP（PiP Companion）隱私權政策

最後更新：2026-10-08

本政策說明幕伴 PiP 如何處理資料

一、帳號與分析
本擴充功能不提供自有帳號或登入系統，也不包含廣告、分析、追蹤或遙測程式碼；開發者沒有用來收集使用者資料的後端伺服器。

二、資料處理
擴充功能會在網頁上尋找影片，並在本機處理字幕、聊天室／彈幕及播放器狀態，以提供 PiP 功能。這些頁面內容不會傳送給開發者。

快捷鍵與功能偏好設定（例如彈幕、截圖與留言區開關）儲存在瀏覽器的本機擴充功能儲存區，不會透過擴充功能同步至開發者伺服器。使用者主動截圖時，圖片會下載至自己的裝置。

為尋找可播放影片，擴充功能會在網頁及符合條件的嵌入框架中執行內容指令碼，並在本機檢查頁面。安裝時瀏覽器可能因此顯示較廣泛的網站存取權限。

三、第三方服務
使用 Bilibili 彈幕功能時，擴充功能會直接向 Bilibili API（api.bilibili.com）請求影片資訊及彈幕，請求會包含影片識別資訊與所需的彈幕區段。請求可能依瀏覽器設定附帶 Bilibili Cookie；Bilibili 對這些請求的處理受其自身隱私權政策規範。除此功能外，本擴充功能不會將資料傳送至開發者或其他分析服務。

其他網站本身的資料處理，則受各該網站的隱私權政策規範。

四、資料保存與刪除
擴充功能只將上述偏好設定保存在瀏覽器本機。移除擴充功能或清除瀏覽器的擴充功能資料，可刪除這些設定。已下載的截圖由使用者自行管理；Bilibili API 對請求資料的保存方式由 Bilibili 決定。

五、政策變更與聯絡方式
政策如有更新，會公布於本文件。若有隱私相關問題，請至專案 GitHub Issues 聯絡：
https://github.com/kir4che/pip-companion/issues
