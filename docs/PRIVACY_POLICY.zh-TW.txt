幕伴 PiP（PiP Companion）隱私權政策

最後更新：2026-10-15

一、資料處理
本擴充功能沒有帳號、廣告、分析或追蹤，也沒有收集資料的開發者伺服器。內容指令碼會在一般網站頁面尋找影片，並在本機處理影片、字幕、聊天室／彈幕及播放器狀態；頁面內容不會傳送給開發者。

快捷鍵、功能開關、跳轉秒數、介面語言、字幕與彈幕外觀設定，以及字幕翻譯偏好設定（例如目標語言與顯示模式）會儲存在瀏覽器的擴充功能本機儲存空間；PiP 使用期間的來源分頁識別資訊、播放狀態及視窗大小與位置則暫存於工作階段儲存區。截圖由使用者主動觸發，並下載至自己的裝置。

啟用字幕翻譯並設定供應商後，擴充功能會將字幕文字與所選目標語言直接傳送給設定的供應商：Microsoft Translator、Google Cloud Translation 或 DeepL。除設定頁連線測試送出的簡短範例文字外，僅在 PiP 字幕翻譯啟用時才會發出翻譯請求；字幕文字不會傳送給開發者。API 金鑰與 Microsoft 區域設定會儲存在瀏覽器的擴充功能本機儲存空間，隨時可在字幕翻譯設定中移除。

二、第三方服務
使用彈幕功能時，擴充功能會從支援網站頁面讀取聊天室／彈幕內容；彈幕（Bilibili、巴哈、Twitch）、字幕及縮圖預覽等功能會直接向相關平台 API 或圖片主機請求資料（包含 Twitch 聊天與表情圖主機）。這些請求可能包含影片識別資訊、彈幕區段資訊及 Cookie，實際內容依功能、請求方式與瀏覽器設定而異。從 PiP 發送彈幕時，訊息會透過網站原生輸入框及使用者的登入工作階段送至巴哈動畫瘋、Bilibili 或 YouTube，不會送至開發者。各服務依其隱私權政策處理資料。

三、保存與刪除
移除擴充功能或清除瀏覽器的擴充功能資料，可刪除本機設定；工作階段資料會在工作階段結束後清除。已下載的截圖由使用者自行管理。第三方請求資料的保存方式由各服務決定。

四、政策與聯絡
政策如有更新，會公布於本文件，若有隱私相關問題請透過專案 [Issues](https://github.com/kir4che/pip-companion/issues) 聯絡。
