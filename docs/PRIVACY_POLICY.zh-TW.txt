幕伴 PiP（PiP Companion）隱私權政策

最後更新：2026-11-06

一、權限與資料處理
本擴充功能沒有帳號、廣告、分析或追蹤，也沒有收集資料的開發者伺服器。內容指令碼會在支援平台（清單見 README）自動執行；在其他網站，只有使用者開啟擴充功能選單並啟用 PiP 後才會注入，Chrome 透過 activeTab 暫時授權目前分頁。擴充功能使用 storage 儲存本機設定、使用 scripting 注入內容指令碼，host permissions 僅限於支援平台，不會要求存取所有網站。影片、字幕、聊天室／彈幕及播放器狀態都在本機處理；頁面內容不會傳送給開發者。

快捷鍵、功能開關、跳轉秒數、介面語言、播放列自訂項目與 PiP 外觀主題色、空降自動跳轉開關、彈幕過濾關鍵字、字幕與彈幕外觀設定，以及字幕翻譯偏好設定（例如目標語言與顯示模式）會儲存在瀏覽器的擴充功能本機儲存空間；PiP 分頁與播放狀態、視窗大小與位置，以及各分頁的額外彈幕來源設定會暫存於工作階段儲存區。瀏覽器工作階段結束時，工作階段資料會清除；關閉分頁時，該分頁的彈幕設定會移除。截圖由使用者主動觸發，並下載至自己的裝置；截圖內容為當下 PiP 畫面，可能包含字幕或彈幕等疊加層。

在 PiP 使用機器翻譯時，字幕文字與目標語言會傳送給所選服務（Microsoft Edge、Google 翻譯、Azure Translator、Google Cloud Translation、DeepL）。擴充功能也可能查詢可用語言；設定頁的連線測試會傳送一小段範例文字。API 金鑰與 Azure 區域設定存於瀏覽器本機儲存空間（免金鑰服務免填）。金鑰只隨請求傳給所選服務，不會傳給本專案；可在字幕翻譯設定中移除。字幕文字不會傳送給開發者。

二、第三方服務
使用彈幕功能時，擴充功能會從支援網站頁面讀取聊天室／彈幕內容；彈幕（Bilibili、巴哈、Twitch）、字幕及縮圖預覽等功能會直接向相關平台 API 或圖片主機請求資料（包含 Twitch 聊天與表情圖主機）。這些請求可能包含影片識別資訊、彈幕區段資訊，以及該網站本身的 Cookie（用於帶入使用者的登入狀態）；Cookie 不會傳給開發者，也不會用於跨站追蹤。實際內容依功能、請求方式與瀏覽器設定而異。僅在使用者主動從 PiP 發送彈幕時，訊息才會透過網站原生輸入框及使用者的登入工作階段送至巴哈動畫瘋、Bilibili 或 YouTube，不會送至開發者。本擴充功能可能接觸的第三方服務包括 Google、Microsoft、Azure、DeepL、Twitch、Bilibili、巴哈動畫瘋與 YouTube，各服務依其隱私權政策處理資料。

三、保存與刪除
移除擴充功能或清除瀏覽器的擴充功能資料，可刪除本機設定；工作階段資料會在工作階段結束後清除。已下載的截圖由使用者自行管理。第三方請求資料的保存方式由各服務決定。

四、政策與聯絡
政策如有更新，會公布於本文件。若有隱私相關問題，請透過專案 [Issues](https://github.com/kir4che/pip-companion/issues) 聯絡。
